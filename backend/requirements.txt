# ── 显式钉住的传递依赖（2026-10-04 补）────────────────────────────
# 起因：本机 venv 里这些包都装着，但 requirements 没写。后果是**换机器重装时会解析出
# 不同版本**，其中两个已经造成过实际问题：
#   · starlette —— fastapi 0.104.1 的 TestClient 直接依赖它；starlette>=0.28 与
#     httpx>=0.28 的组合会让 `TestClient(app)` 抛
#     TypeError: Client.__init__() got an unexpected keyword argument 'app'
#     （httpx 0.28 移除了 app= 参数）。本项目 39 个 tests/test_*.py 里有 2 个用 TestClient，
#     不钉版本就等于这 2 个测试在别的机器上永远跑不了。
#   · numpy —— pandas / scikit-learn / torch / embedding 的公共依赖，不钉会让新环境
#     装到 2.x 头版本，与本机 2.4.6 行为不一致（numpy 2.x 对 float(数组) 直接抛 TypeError）。
# 这两个是「不写就要出事」的，其余（pillow / tokenizers / safetensors / huggingface-hub）
# 由各自上游包带入，版本随sentence-transformers 走，不必钉。
